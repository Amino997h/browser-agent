# 🤖 Browser Agent (الوكيل الذكي للمتصفح)

وكيل ذكاء اصطناعي محلي يتفاعل مع المتصفح لإنجاز المهام المطلوبة تلقائياً باستخدام النماذج اللغوية (LLMs) وتقنية Playwright. المشروع مزود بواجهة ويب (UI) تتيح لك إدخال الأهداف ومتابعة خطوات الوكيل في الوقت الفعلي.

## ✨ المميزات (Features)
- 🧠 **تكامل مع النماذج المحلية:** يدعم أي خادم API متوافق مع OpenAI (مثل الخوادم المحلية أو بروكسي ChatGPT).
- 👁️ **واجهة ويب تفاعلية:** مبنية باستخدام FastAPI و WebSockets لعرض السجلات والمراقبة المباشرة.
- 🛡️ **تخطي حماية البوتات (Bot Evasion):** يستخدم بيئة تصفح فعلية ويقوم بحفظ ملفات تعريف الارتباط (Cookies) وتجاوز رسائل الاختبار الآلي.
- ⏸️ **التعامل الذكي مع الكابتشا:** يتوقف الوكيل مؤقتاً (Pause) عند مواجهة صفحات التحقق البشري (Captcha)، ليسمح لك بحلها، ثم يُكمل العمل بضغطة زر.

## 🛠️ المتطلبات الأساسية (Prerequisites)
- Python 3.8 أو أحدث.
- متصفح Google Chrome (أو Microsoft Edge) مثبت على النظام.

## 🚀 طريقة التثبيت (Installation)

1. **استنساخ المستودع:**
   ```bash
   git clone https://github.com/Amino997h/browser-agent.git
   cd browser-agent
   ```

2. **تثبيت الحزم المطلوبة:**
   ```bash
   pip install -r requirements.txt
   ```

3. **تثبيت متصفحات Playwright:**
   ```bash
   playwright install chromium
   ```

4. **إعداد متغيرات البيئة:**
   - قم بنسخ ملف `.env.example` إلى ملف جديد باسم `.env`.
   - افتح ملف `.env` وقم بتعديل بيانات الـ API لتناسب سيرفرك المحلي:
     ```env
     OPENAI_BASE_URL="http://127.0.0.1:8008/v1"
     OPENAI_API_KEY="sk-chatgpt-local-secret-key"
     OPENAI_MODEL="gpt-4o"
     ```

## 🎮 طريقة التشغيل (Usage)

**لأنظمة Windows:**
- انقر نقراً مزدوجاً على الملف `run.bat`.
- سيتم تشغيل الخادم وتفتح واجهة الويب تلقائياً على الرابط `http://127.0.0.1:8000`.

**طريقة التشغيل اليدوية (أي نظام تشغيل):**
```bash
python web.py
```
ثم افتح متصفحك على الرابط `http://127.0.0.1:8000`.

## ⚙️ كيف يعمل؟
1. أدخل هدفك في الواجهة (مثال: "افتح فيسبوك وسجل الدخول").
2. يقرأ النموذج اللغوي الهدف ويحدد الرابط الأولي المناسب.
3. يقوم Playwright بفتح المتصفح ومسح عناصر الصفحة (Scraping) مثل الأزرار والروابط والنصوص.
4. يُرسل الوكيل هذه البيانات للنموذج ليقرر الخطوة التالية (نقر، كتابة، رجوع، أو نجاح المهمة).
5. تدور هذه الحلقة حتى يعلن النموذج نجاح الهدف أو توقفه.
